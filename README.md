# Raysis V2 Staging

Isolated staging copy of the Raysis Printing House Management System V2.

- Source: `raysis-v2-combined-upgrade` development branch.
- This repository is for staging validation only; it is separate from the live production repository.
- Browser data, cached profiles, and Supabase authentication storage use staging-specific keys.
- Supabase project configuration currently points to the existing Raysis Supabase project. Do not use this staging app for live business transactions.
- GitHub Pages can be enabled after the staging files are verified.
